# Emergent Light 1.5.0 · 经典生态与浮动控制台

这是该版本的独立源快照。运行 npm ci、npm run dev 体验浏览器模拟；Windows桌面版需Node.js、Rust、C++构建工具及WebView2，执行 npm run tauri -- build。构建工具需与目标架构一致。

历史版本只用于体验各阶段功能，不代表当前推荐版本。不同版本共用应用标识；切换前应导出预设，旧版本不支持全部新版参数。

完整项目介绍和现行文档见仓库main分支。此快照排除旧开发对话文档和本机环境记录，保留对应版本代码、配置及验证数据。安装包重建时额外启用Rust构建路径去标识与通用PDB路径。
