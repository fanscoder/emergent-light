# v0.8.2 单侧白边修正（已通过稳定性验收）

残余白边只在上边或某一侧。检查 Tao 0.37.2 源码发现无装饰阴影模式仍在 WM_NCCALCSIZE 中按 DPI 保留绘图区边距。本版关闭壁纸阴影、抑制 Windows 11 DWM 描边；使用主显示器 rcMonitor 完整边界，转换到桌面宿主坐标，避免工作区尺寸或坐标混用；清除最大化标志以避免框架将客户区限制到 rcWork。返回设置恢复阴影和默认描边。未实测前不认定白边根因已证实。

验收：从普通窗口和最大化窗口分别进入壁纸，观察上边及侧边是否仍有白线；托盘返回设置的边框、阴影和交互应恢复正常。无需改变系统缩放或分辨率；多屏与热插拔尚未承诺支持。

技术验证：TypeScript/Vite 构建、Windows release 和 NSIS 安装包构建通过；测试 93 通过、1 跳过。随后通过稳定性验收。
