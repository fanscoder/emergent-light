# v0.9.3 兼容性与帧率维护


## 2026-11-05：v0.9.3 维护验证包：25H2 宿主与帧率

阶段需求为只做维护。报错电脑已确认使用 Windows 25H2，截图显示旧版宿主识别失败。实测同时出现桌面有无窗口均受到帧率限制，明确要求优先效果、关闭非聚焦时的帧率下调。

宿主修正：保留经典顶层空白 WorkerW，增加 Progman 子级 WorkerW 识别；发现 WS_EX_NOREDIRECTIONBITMAP 和直接图标层时使用新版分离桌面路径，应用作为 layered 子窗口置于图标层之下、系统背景层之上，以 alpha255 合成。创建消息后重新探测合成标志，尝试三组已知参数；未知结构仍保留可交互设置窗口，增加图标层与合成结构诊断。没有隐藏桌面图标、修改其他系统窗口或自动重启 Explorer。该方向与 25H2 结构相符，尚未在报错电脑验证，不能认定已解决。

帧率修正：删除前端 reduced 模式和约 30FPS 的调度分支。可见/部分遮挡/非聚焦都使用正常动画循环，不再主动限至 30FPS。保留可关闭的完全遮挡、安全桌面、系统熄屏休眠及手动暂停；未知遮挡保持运行。系统/WebView 自身的调度限制仍不能由应用保证消除。模拟、光效和互动参数不变。

参考：https://github.com/lively-community/lively/issues/2074 （维护者转述的新式桌面合成结构）及 https://github.com/Ivy-Interactive/Ivy-Windows-Wallpaper （Progman 路径说明）。

验证：TypeScript/Vite、Windows x64 release 与 NSIS 构建通过；前端完整测试 106 通过、1 跳过；原生 6 通过，包含经典/新式/子级宿主选择、未知结构拒绝及节能区域计算。已加入部分遮挡仍选择 normal 的回归断言。宿主单元测试是合成拓扑，不代表所有 Windows 机器实测。

实机验收：退出旧版、安装并在系统组确认 v0.9.3；25H2 电脑点击桌面壁纸，确认图标、右键、任务栏及托盘返回可用；桌面空白、普通窗口遮挡、非聚焦时均不应再显示主动 30FPS 节能状态。若宿主仍失败，提供完整新提示。原多屏/热插拔/Explorer 重启恢复限制不变。
