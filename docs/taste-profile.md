# 视觉与交互设计规范

本规范将历次视觉校准归纳为产品约束，不记录个人背景或对话评价。具体参数是对应版本的实现选择，不应脱离当前代码直接沿用。

## 视觉目标

深海生物发光意象：深蓝黑背景、小而可辨的核心、柔和光晕、疏密变化。运动应持续、自发、可观察，避免长期冻结，也避免高频扰动淹没结构。偶发的剧烈事件应保持局部、短暂且可辨。

## 亮度与时间

- 暗色优先。密集叠加不能迅速烧白，核心与光晕应分层控制。
- 亮度响应进行时间平滑，避免瞬时速度变化引发闪烁。
- 呼吸以常态亮度为谷底，缓慢增强；周期可在数秒范围内缓慢漂移，不使用明显方波节拍。
- 拖尾清洁应兼顾连续性与底色纯净，避免周期性整屏硬清空。
- 渐变采样与适量抖动用于抑制色带，但不得向透明区域注入会被加色累积放大的底噪。

## 行为与装饰

常规运动由模拟规则产生，不用预设轨迹冒充涌现。形状彩蛋应明确属于外部初始条件或装饰事件，之后允许结构自然解体。现有苦力怕形状使用绿色系线索，不将其视为物种属性。

出生与捕食事件应从自身光晕中辨认出来，但不使全屏持续闪烁。出生提示跟随子代；非致死普通冲突与自然老化不必使用同等强烈的事件提示。

## 进化表型

| 外观 | 表达属性 |
|---|---|
| 核心半径 | 寿命倾向 |
| 芒尖锐利程度 | 进攻欲望 |
| 芒尖数量 | 攻击强度 |
| 核心延展 | 速度倾向 |
| 侧点、外弧 | 群体性、差异容忍度 |
| 缓慢变化的色相 | 家族特征 |

成年轮廓保持相对稳定，当前能量主要通过光晕与亮度表达，幼体叠加成长比例。表型用于观察遗传差异，不赋予固定职位或类别。

## 地理与界面

地理线索采用暗淡底色与边界带，通道保持可辨；不覆盖精灵，也不在光晕中持续累积。显示可独立关闭。

控制台采用可拖动、调尺寸、折叠的浮动面板，参数按类别收纳。滑条附数值与机制提示；提示描述实际作用，不保证特定生态结果。桌面模式通过托盘返回设置，快捷键为补充入口。调试参数默认隐藏。

## 校准方法

验收同时关注持续运动、结构辨识、亮度舒适、线索时空一致性与操作便捷性。视觉验收与类型检查、回归测试、性能测量分别记录，不能互相替代。版本演变详见[开发历程](history/README.md)。
