# 初始产品愿景与设计原则

本文件概括项目初期目标，不保留原始对话、个人背景或对开发工具的委托指令。

项目定位为实时复杂系统模拟、生成艺术与桌面应用。简单局部规则应能够产生持续变化的集体结构，兼顾动力学可信度与长期观看的视觉舒适度。

## 初始目标

- 先实现可复现的跨平台浏览器原型，再评估桌面壁纸封装。
- 以粒子生命和鱼群为基础，探索聚集、分层、流动、稳定与重组。
- 将真实涌现行为与视觉美感列为同等重要的验收维度。
- 风格为深邃、安静、朦胧的生物发光与暗色空间，不转为普通装饰粒子动画。
- 常规运动来自规则，不用人工编排轨迹冒充模拟结果。

## 工程原则

模拟与渲染分离；控制随机种子；提供参数实验、暂停与重置；尽量复用邻域查询和状态存储。性能、可复现性与视觉验收分别验证。后续桌面、生态、遗传和地理阶段应保持上述方向，但具体技术以当前架构文档为准。

该愿景演变为现有五模式、Windows壁纸与独立遗传生态。阶段实现和替代方案见[提交时间线](commit-timeline.md)及各版本记录。
