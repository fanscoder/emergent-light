# v1.1.0 第一轮：不同景观与能量事件（待视觉验收）

2026-11-05。范围仅为群猎/独猎与捕食、出芽线索；不加入头领、捍卫者或遗传变异。

## 两种景观

- 生态鱼群：保持 v1.0.0 的捕食者局部对齐、结群、共同追逐和繁殖参数。两组300秒测试的种群结果与v1.0.0逐项一致。
- 生态粒子生命：捕食者不再相互吸引或对齐，在110个基础单位范围内排斥同类，增强个人方向偏好；被捕食者仍同类优先、青色与琥珀混群，聚集作用增强以形成更集中的生命岛。
- 独猎捕食者能量门槛1.75，成熟年龄45秒，出芽最小间隔75活动秒；繁殖后亲代保留原能量45%、幼体35%，其余为成本。唯一新增个体记录是上次出生/繁殖时间，死亡压缩数组时同步搬移。不能通过重置寿命年龄实现冷却。休眠不推进这些计时。

## 视觉线索

- 真实捕食成功在猎物消失的位置生成暗红微光，持续0.65活动秒；出芽在幼体位置生成青绿微光，持续1.4活动秒。自然衰老和饥饿仍用已有渐隐，不额外闪光。
- 连续正弦平方包络，首尾为零；半径约5–7 CSS像素，最大核心透明度分别0.42/0.32，光晕精灵自身峰值透明度低于0.3。不使用白色或加色叠加。
- 独立透明画布每帧清除，绝不向拖尾历史写入事件光。无事件且上一帧干净时跳过事件层绘制。鼠标穿透、面板层级保持。
- 最多同时6处；空间上相近的事件（包括不同种类）合并，不重新启动原提示，防止密集捕食/繁殖形成连续闪烁。视觉省略不影响真实事件计数。
- 事件使用独立的有界数据记录，不抽取物理随机数，也不改变能量、种群或轨迹。

## 验证与边界

前端完整测试131通过、1跳过；原生6通过；类型、Vite、Windows发布构建与NSIS打包通过。完整测试后对无事件时跳过透明画布清屏作了小幅渲染优化，重新通过类型检查与生产构建；生态源码未再变化。

专项测试覆盖群猎接近/独猎远离、75秒休整、真实捕食与出芽事件、自然死亡不闪光、事件预算/合并/平滑边界、填满视觉预算不影响物理轨迹。两种模式、两个种子各300模拟秒无救援测试通过；默认种子20261014各900模拟秒并记录最近捕食者距离和人口账目。
