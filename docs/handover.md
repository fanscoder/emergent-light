# 维护指南

当前实现：v2.3.0。本文概括维护入口和验证要求；历史版本细节见各release文档。

## 项目定位

实时局部规则驱动的生成艺术与生态模拟，提供浏览器体验和Windows动态壁纸。视觉目标为暗色、柔和光晕、持续但不过度剧烈的运动。模拟行为与装饰效果应明确区分。

## 入口与结构

| 位置 | 职责 |
|---|---|
| src/main.ts | 模式、参数、平台与渲染接入 |
| src/core/modes/ | 粒子生命、鱼群、旧生态及独立进化内核 |
| src/core/genetics.ts | 八轴遗传、相似度、重组与突变 |
| src/core/evolution-environment.ts | 种子地理、资源和通行阻力 |
| src/core/evolution-observation.ts | 近期窗口与相似类群估算 |
| src/render/ | 光晕、拖尾、事件线索及地理背景 |
| src/ui/、src/platform/ | 浮动面板、预设及平台功能 |
| src-tauri/src/ | Windows桌面宿主、托盘和节能 |

## 开发与构建

使用与目标架构一致的Node.js、Rust工具链和依赖。浏览器开发执行npm ci、npm run dev；正式资源执行npm run build；回归执行npm test。Windows打包执行npm run tauri -- build，需要C++构建工具与WebView2。安装产物位于src-tauri/target/release/bundle/nsis。

## 核心约束

- core不依赖DOM或Canvas；渲染器只读模拟状态。
- 相同版本、种子、参数和运行条件应可复现；不承诺跨版本轨迹一致。
- 优先使用空间哈希与有界缓存，避免截断邻居而隐式改变模拟规律。
- 新进化规则仅作用于独立进化模式；旧模式的稳定行为单独维护。
- 能量和人口必须有可核对的账目，不以隐藏奖励或保种替代生态规则。
- 地理显示与实际资源、阻力读取同一地图，背景按普通渐隐合成，避免加色积累。

## 验证

源码与配置变更运行类型检查、相关回归和正式构建。生态变更额外检查多个种子、人口/能量账目、参数边界及关闭救援后的行为；界面变更检查正式资源、模式切换和预设恢复。有限模拟样本不等于无限自维持的证明；桌面、DPI和多屏行为只在实际验证范围内作支持声明。

## 统计解释

当前相似类群是基因距离的近似分组，不是固定物种。祖系字段在双亲中择一继承，仅为来源标签，不是完整家谱。近期死亡年龄采用约120秒模拟时间窗口并标注样本量；累计计数应明确区分。关闭所有繁殖不会关闭独立的迁入救援。

## 常见维护问题

- 拖尾与加色混合可放大微弱底噪，应检查光晕尾部、合成方式与渐隐平均值。
- 全局亮度采用慢变连续调制，避免周期性硬清空导致可见闪烁。
- Windows未知宿主结构保留可交互设置窗口，不修改系统图标或强制重启Explorer。
- 后台节能不应因窗口失焦而降低仍可见桌面的画质。
- 实验数量上限只表示容量支持，不保证设备帧率。
