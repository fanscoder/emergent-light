# v1.2.0 头领


## 2026-11-06：v1.2.0 头领第一轮（待视觉验收）

开始头领阶段。本轮实现两种生态模式的被捕食者头领，以及仅围猎模式的捕食者头领；捍卫者/同归于尽/饥饿攻击50%存活另轮实现，不含遗传变异。

头领从现存成人个体中选举，不增人口，不继承给幼体。每3活动秒检查：同种90×世界尺度范围内至少8个被捕食者邻居或4个捕食者邻居；候选年龄至少12秒，能量至少0.4；优先邻居最多者，确定性平局按索引，不消耗RNG。每次每物种最多提升1个，已有同种头领180×尺度范围内不产生新头领。全局青色最多4、琥珀最多2、围猎捕食者最多2；角色维持到死亡，避免群体稀疏时反复闪变。新生角色归零，移除换位复制角色，重开清空。身份用单个Float32数组保存并兼任4秒平滑显现强度，原有非生态模式不受影响。

普通同类对头领社会权重5倍；鱼群额外有限吸引力，避免原平均归一化抵消单邻居偏好。普通捕食者相互跟随权重和响应下调。头领保留更强个体方向；鱼群响应由少量普通邻居的约0.12渐增至大群0.8，生命模式降低普通社交影响但保留人数叠加，摄食/逃生仍有效。同种头领150×尺度内柔性排斥，不设硬墙，青色琥珀混群仍允许。不会编排路线或保证固定队形/汇群概率。

核心外3.4 CSS像素、0.75像素线宽细环，沿用本体核心色，4秒平滑显现，随寿命/亮度衰减；和事件共用独立透明覆盖画布，保持相同环绕插值，不写进拖尾。生态面板说明头领标记与群猎30秒繁殖间隔。出生/捕食提示与30/75秒繁殖门槛保持v1.1.2。

验证：前端完整142通过、1跳过，原生6通过，类型/Vite、Windows release及NSIS安装包通过。新测试覆盖大群选举、幼体/孤立个体排除、限额/跨边界间距、独猎无捕食头领、普通跟随/头领排斥、密集群体响应、角色数组压缩/出生不继承/重开、活动时间与平滑确定性。四组5分钟救援关闭均保留两级种群。两个模式各15分钟默认运行完成、人口账目正确、头领限额通过，见版本化JSON。最终样本：
