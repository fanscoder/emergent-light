# v0.9.0 互动与彩蛋

使用方法：在控制台下方“互动与彩蛋”区域选择光标互动模式；点击“预览苦力怕脸”或“预览钻石”；勾选“偶尔出现彩蛋”开启自动事件。两个开关默认关闭且保存选择。测试桌面模式前可先在窗口里确认力度和轮廓。


## 2026-11-05：v0.9.0 互动与彩蛋（待视觉验收）

下一版本主题为“互动与彩蛋”，明确要求 Minecraft 苦力怕脸、钻石图像彩蛋及可选的光标吸引/避让。本版以手写像素轮廓实现两种出生印章：重新排布最多一半粒子，同步 prev 防跨屏插值，保留粒子种类与总数，降低初速后立即交回真实动力学，不用持续导向力伪装成涌现。

两种模式共用 core/interaction.ts，独立种子事件 RNG 不消耗原模拟随机序列。手动预览与可选自动出现（约 180–360 模拟活动秒）均已接入；暂停不会累积自动事件。光标互动默认关闭，局部平滑有限力叠加到模拟加速度，速度仍由原积分器限幅。浏览器/设置窗口使用指针事件；桌面模式启用时低频查询 GetCursorPos，检查光标下方根窗口属于 Progman/WorkerW 后转换到归一化客户区坐标，避免在其他应用窗口上操作时牵动壁纸。不截获桌面点击。

控制台新增“互动与彩蛋”区域，互动模式和自动彩蛋开关独立保存在 localStorage，不并入原模拟预设 JSON。两个选项默认关闭。手动暂停时预览会提示先恢复。

修改文件：src/core/interaction.ts 及测试、两种模式与共享接口/测试替身、src/platform/playground.ts、组装入口、Rust 桌面桥接和版本配置。验证：TypeScript/Vite 构建、Windows x64 release 和 NSIS 打包通过；99 项测试通过、1 项跳过。新增测试覆盖局部力方向与关闭、同种子印章可复现、两种模式继续演化、粒子总数、插值历史和自动活动时间。

尚待实机验收：桌面光标坐标与穿透交互、图案辨识度和解体速度、亮度与稠密结构观感；不承诺图案维持固定时长。没有持续固定图案或编排粒子轨迹。后台节能仍未实现；多屏等旧限制继续适用。下一步根据实测结果调校。
