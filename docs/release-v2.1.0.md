# v2.1.0 Mutant and Evolution · 稳定谱系

## 2026-11-07：v2.1.0 稳定谱系、相关变异与可辨识表型（待实机视觉验收）

仅更新独立“变异与进化”模式，保留既有四种模式及其生态规则。新增寿命longevity、速度pace，八轴参与继承和相容性。寿命倍率0.65–1.55，速度基准倍率0.7–1.3；成熟等待12–28活动秒，繁殖间隔14–36活动秒。高速与高战力增加代谢，高战力略降速度上限。速度仍受能量与既有非遗传个体微差影响，不保证实际速度等于基因上限。

变异改为出生级事件，默认12%概率，通常只变一个位点，8%变异事件选择两个不同位点。未选中位点精确继承；色相位点权重0.15、步幅0.45倍，家族色变化较慢。软关联仅影响被选中位点的变化方向，不强制划分类别，不把每代全部属性拉向模板。偏草食降低攻击欲望、增加群体性；中间食性群体性向0.5靠拢；偏肉食提高攻击欲望，群体性保留独行和群居可能；低群体性肉食增加长寿与战力倾向；攻击能力和欲望仅弱相关，食性不直接决定战力。所有方向保留逆向变异机会。初始个体仍独立采样，因此不会立即生成预设脸谱。

进攻改为每秒事件率换算，交锋间隔6秒，幼体前6秒不作为主动目标。普通交锋消耗已有能量并退让4秒；仅一方能量低于0.12，或明显力量差且发起者偏肉食并饥饿时，才进入致死结算。普通排斥仍首先是驱离，不直接等同攻击。不引入额外生命值与人为身份。新lineage字段只用于统计存活祖系，绝不参与行为或固定物种划分；不保留无限死亡家谱。

已确定的视觉映射已实现：核心半径=寿命倾向；芒尖锐利=进攻欲望；3–6芒尖=攻击强度；核心延展=速度；侧点/外弧=群体性/容忍度；慢变色相=家族。成年身份轮廓不随能量缩放，能量仍改变光晕亮度，幼体保留成长比例。观察区新增八轴说明、存活家族/最大家族、非致命交锋和平均死亡年龄。平均死亡年龄包括预置为成体的初代，不能解读为从启动起的实际生存时长。

geneSchema升级2；接受schema1参数预设并按新规则从种子重建，未知版本仍报错。预设不是个体快照，旧变异数值沿用但语义变为出生概率。实际双亲繁殖、持久族群制度本轮未加入。

验证：共享回归此前173通过、1跳过；最后群体性关联修正后，进化专项12项重新通过。三个种子各300模拟秒、关闭救援的最终版本长测通过基因边界、人口/能量账目；与2.0.0同种子但不同基因架构做描述性比较，并非相同初始世界。结果见下表。原生6项、TypeScript/Vite及Windows release/NSIS安装包通过。生产浏览器9组检查此前通过，最终关联修正未改变界面代码。旧生态内核未修改，未重复其长测。
