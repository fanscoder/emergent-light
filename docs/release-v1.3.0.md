# v1.3.0 护卫者


## 2026-11-06：v1.3.0 护卫者（待视觉验收）

要求加入此前讨论的护卫者，并补足粒子生命头领前方的个体。已先补交v1.2.1基线194e59d，维护安装包与交接记录归档完成。

两种生态模式均每3活动秒从头领100×尺度附近已有同类成人中选护卫，每位被捕食者头领最多两名，不额外生成个体。候选年龄≥12秒、能量≥0.35；护卫不兼任头领、子代不继承。角色上限12人，头领消失/变种/越出240×尺度时解除；数组压缩重映射，重开清空，生命周期照常。护卫牺牲后该头领至少30活动秒不补员，避免不断补充护卫压制捕食者。

平时目标位于头领运动方向前方约32×尺度、左右各16×尺度，有限站位力与速度匹配，保留分离、觅食和鼠标力。护卫降低普通社交吸引（鱼群响应0.3，生命模式0.04倍），不被后方大群拉回；速度上限允许1.1倍以追上站位。普通鱼群尾随与头领附近繁殖规则、粒子生命普通个体与独猎规则保持v1.2.1。前方站位是软约束，不锁位置或固定编队。

护卫只迎击55×尺度内、已逼近头领32×尺度或头领最近2秒受过攻击的捕食者。非极饿捕食者在护卫35×尺度内柔性避让且不将护卫作为食物目标，仍可捕猎外围普通个体；能量低于0.45才主动冒险。接触时护卫必死：普通捕食者同归于尽；极饿捕食者有50%概率存活并获取能量，否则两者死亡。战斗使用独立种子RNG，不与运动随机采样混合。每只捕食者每模拟步最多结算一场迎击，防止多名护卫重复结算；死亡清除在所有邻居查询之后进行。

统计新增guardClashes和defenseDeaths；极饿捕食者获胜只计一次捕食，互灭计两次防御死亡，不重复计为饥饿/老死；账目为初始+出生+迁入-捕食-防御死亡-饥饿-老死。战斗沿用原小范围暗红死亡提示与6处合并上限，不增加全屏闪烁。护卫采用同色两个小侧点，3秒平滑显现、解除后2秒渐隐，沿用透明覆盖层与环绕插值，不写入拖尾；头领四芒星保持。

验证：完整前端162项通过、1跳过，护卫针对性12项通过；原生6项通过；类型、Vite、Windows release及NSIS安装包通过。测试覆盖招募人数/物种/年龄、环绕距离/解除、死亡与换位重映射、出生/重开、饥饿分支约50%、实际两种战斗结局/能量/人口账目、两模式前方力、粒子生命后方大群下持续前置，以及牺牲后的补员冷却。
