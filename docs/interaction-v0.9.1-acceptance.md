# v0.9.1 绿色苦力怕与精简面板


## 2026-11-05：v0.9.1 绿色苦力怕与精简面板（待视觉验收）

澄清钻石原意为 Minecraft 钻石，但决定移除钻石，只保留苦力怕脸，并要求组成精灵采用绿色系。另要求按类别折叠控制面板，加入开机自启、版本号和使用指南。

本次删除钻石模板及预览入口，自动事件仅生成苦力怕。增加独立 eggTint 可视标记：组成脸的粒子维持绿色约 9 秒，再用预计算的 16 档调色过渡在约 3 秒内回到原色；随机重开和粒子重生清除标记。仅更改颜色映射，不更改物种或光标力。预计算光晕精灵覆盖颜色过渡，未提高光晕亮度参数。

控制面板分为模式与预设、显示与性能、视觉效果、模拟参数、互动与彩蛋、系统与使用指南六组。使用原生 details/summary，首次仅基础组展开；折叠状态持久化，切换模式/导入预设时恢复选择。系统组显示安装版实时版本号、自启开关、托盘操作、Ctrl+Alt+P 和退出方法。自启通过同一原生命令连接面板与托盘并广播变化；浏览器明确提示桌面能力不可用。

验证：TypeScript/Vite 生产构建、Windows x64 release 和 NSIS 打包通过；101 项测试通过、1 项跳过。新增测试覆盖绿色占优色板、普通颜色不变、颜色过渡结束及不改变粒子种类；检查 src 中已无钻石模板和入口。未自动操作实际开机启动或注销来测试系统启动。实际面板、绿色观感和自启效果仍待

修改涉及模拟共享可视状态、彩蛋模块、渲染颜色与精灵、折叠控件、系统面板和原生自启同步。鼠标互动参数保持不变。下一步按视觉验收结果微调，不预先打稳定版标签。
