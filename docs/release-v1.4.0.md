# v1.4.0 种群详细设置


## 2026-11-06：v1.4.0 种群详细设置，1.x阶段收尾（待面板验收）


新增默认折叠“种群详细设置”，内含青色/琥珀/紫色三个折叠组。各开放寿命（30–1200秒）、速度（5–160参考像素/秒）、繁殖间隔（0–300秒）、成熟年龄（2–180秒）、繁殖能量（0.6–1.79）。数值输入支持小数，非法/非有限值不生效，导入会钳制边界；每个种群可恢复默认。未手动修改的项标“随模式”，继续受原全局寿命/速度及模式繁殖规则控制；手动项采用绝对基准。参数在现有预设中保存，不新增另一套存储；切换模式未保存的参数按原流程重新初始化，需保存预设。

寿命延续原0.75–1.25个体比例，修改时只同比调整该种群现存个体的寿命，不改年龄；缩短导致超龄的个体会在下一步自然消失。速度延续原能量/个性/护卫修正，数值是基准而非恒定速度，空间尺度随画布适配。自定义繁殖间隔按现有个性在基准±16%范围浮动，不新增随机采样或遗传；0表示无额外冷却，仍受成熟、能量与人口上限约束。鱼群远离头领时保持3倍间隔、1.5倍成熟年龄及更高能量门槛；能量门槛上限低于储能极限，防止设成物理上达不到的条件。头领/护卫共享其物种基准，身份与战斗规则保持。

实现采用15个扁平预设参数，-1表示沿用模式；旧预设缺省项自动回退。每种群预计算缓存，步进时使用三个已解析配置，避免逐个体动态键与临时闭包开销。恢复默认也恢复实时寿命基准；预设导入、重开仍保持确定性。

验证：前端170项分批通过、1跳过；原生6项通过；TypeScript/Vite、Windows release与NSIS在新位置构建成功。新增测试覆盖旧预设/配置往返与同种子轨迹、现存寿命同比/年龄保留/恢复、物种速度隔离、非法值和边界、个体间隔差异及能量供给下的冷却。四组各5分钟救援关闭的最终生态统计与v1.3.0逐项完全一致，见docs/ecology-validation-v1.4.0.json；未重复默认15分钟长跑。首轮长测合并两个种子计时出现超时，已缓存热路径并将每种子拆为独立5分钟测试，每项仍120秒、保留所有断言及耗时；最终生态文件14项全部通过，与其余156项已通过的回归合计170项。未实测任意自定义配置的长期平衡；开放调参可能改变种群存续，恢复默认可回到已验收生态。
