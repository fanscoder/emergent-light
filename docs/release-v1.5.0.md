# v1.5.0 悬浮游戏控制台


## 2026-11-06：v1.5.0 悬浮游戏控制台与种群滑条（待实机验收）

确认执行可拖动、调尺寸、整块折叠、界面大小和布局记忆的游戏菜单式面板；同时认为上一轮数值框不美观，要求种群属性改为拖动条。

标题栏拖动、释放时约12像素边缘吸附；右下角拖动调整宽高，也支持方向键10像素/Shift30像素调整。小/标准/大三级界面大小为0.85/1/1.15，字体与主要控件间距响应，面板尺寸同比调整；不缩放模拟画布。整块收起保留窄标题栏，按钮或双击标题栏展开。所有面板位置、展开尺寸、界面大小和整块折叠状态单独写入localStorage键emergent-light-panel-layout-v1；无存储/坏数据回退默认；窗口缩小/显示变化时限制在可见区域；标题栏复位按钮恢复布局，不更改物理参数。原分类折叠状态继续保存。

模式、暂停/继续、换种子提到固定快捷区；预设/壁纸操作保留在预设与桌面分类。内容独立滚动，标题与快捷操作保持可见；半透明深海底、细边框和柔和阴影。壁纸模式仍隐藏整个面板，通过托盘返回设置窗口，未更改桌面穿透或系统快捷键。

两种生态模式的15个种群数值框改为原生range滑条，显示即时值，时间附秒单位；悬停/辅助技术可读单位与默认/手动基准状态。寿命/间隔/成熟步长1，速度/能量0.01，支持键盘方向键；数值跟随预设导入、物种恢复与模式变化。调参说明改为默认折叠的帮助，生态观察默认收起，但尊重此前已保存的展开选择。核心生态规则、参数边界及预设协议不改，原种群恢复按钮保留。

验证：TypeScript与生产Vite通过，UI测试10项通过（含新增3项布局边界/折叠恢复/坏存储状态），原生6项通过，Windows release和NSIS通过。独立Edge无界面生产构建验收9组：真实指针拖动/缩放尺寸、界面大小、收起展开、刷新保留折叠布局、小视口边界、布局复位、15条种群滑条修改及物种恢复；结果见docs/ui-validation-v1.5.0.json。截图保存在工作区desktop-stage/ui-v1.5.0.png，检查了深色面板和完整种群滑条布局。没有重跑与本次纯界面改动无关的生态长测。
