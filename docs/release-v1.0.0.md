# v1.0.0 — Life and Competition（首轮验收版）

2026-11-05。网络中断后检查确认源代码和测试数据均保存，随后继续完成打包与归档。

## 已实现

- 新增生态鱼群（局部对齐）与生态粒子生命（非对称吸引/逃避、距离作用）两个独立模式。原有 boids.ts 与 particle-life.ts 无修改，原模式继续可选。
- 青色和琥珀为初级消费者，同类优先、允许混群；紫色为捕食者。持续加入微小、无光晕、仅随缓慢洋流移动的营养颗粒。
- 个体仅新增核心状态“能量”，复用年龄、寿命、个性和大小差异。不加入遗传、变异或独立成长属性。
- 摄食补充能量，日常代谢消耗能量；能量平滑映射到光晕和中心大小/亮度，少量影响速度上限，保留饥饿时的基础游动能力。
- 能量达到 1.6、年龄至少 12 秒才出芽：亲代保留原能量的 55%，幼体获得 35%，其余作为繁殖成本。幼体与亲代同种，个性重新独立采样；在附近出生、随亲代初始速度游动，逐渐显现，随后独立摄食。无固定跟随轨迹。
- 保留寿命和饥饿死亡，捕食后移除猎物，死亡不原地自动复活。每 20 秒检查低种群，必要时每类最多迁入一只；救援可关闭且单独计数。
- 动态种群容量最多 450，默认繁殖上限 420；降低上限不强制杀死现有个体，而是抑制新生。营养颗粒上限 1400，防止资源无限累积。
- 支持参数热调节、种子、规则预设保存/导入、鼠标互动、绿色印章及现有桌面功能。生态印章不重置个体年龄，也不创造能量。自动暂停不推进生态时间。
- 折叠面板新增生态观察：物种数量、食物、出芽、捕食、迁入。种群初始数、上限、营养供给、速度、寿命和救援可调。

## 使用与待验收

退出旧版后安装 src-tauri/target/release/bundle/nsis/Emergent Light_1.0.0_x64-setup.exe。在“模式与预设”中选择“生态鱼群”或“生态粒子生命”。旧预设会继续打开原模式，这是兼容行为。观察青/琥珀取食、紫色追逐、幼体出生与能量光晕；可展开“生态观察”。

尚未做实际 GUI 观感与渲染耗时验收；不同屏幕、分辨率和参数配置可能改变观感。多屏、Explorer 重启恢复等既有平台限制继续适用。当前为 v1.0.0 首轮验收构建。
