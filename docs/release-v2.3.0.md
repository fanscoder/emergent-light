# v2.3.0 种子地理与双亲繁殖

## 2026-11-07：v2.3.0 种子地理、暗色线索与双亲繁殖（待实机验收）

阶段需求为2.2.0还不错，要求地理视觉提示、种子生成不同地理，并接入交配，出芽变为低概率且可关闭。新内容仍仅作用于独立进化模式，旧四模式保留。没有加入新的遗传轴、固定身份、遗传树界面或多胎系统。

地形从固定三列两行改为种子决定2–4列、2–3行（4–12区域），并生成两轴曲线剪切幅度与相位，构成周期环绕的弯曲网格。双剪切可逆且保面积，资源场、区域判定、阻力带、通道和中心位置使用同一坐标变换。资源中心权重种子采样后归一化均值1，拒绝采样上界改为实际最大权重；不增加总foodRate。不是只打乱固定六格资源。相同种子同版本可复现；换种子会变数量/轮廓/通道/资源。缩放屏幕保持归一化地理。

ParticleStore.habitat提供同一地图与环境/显示/差异/阻力参数。Canvas使用192×128缓存底图，地图或参数变化时才重建；暗淡底色随资源略亮、边界带随阻力显现，低阻通道自然变淡。不叠加到光晕累积层，而作为原背景渐隐目标，用同一fadeAlpha做source-over，避免固定地形不断加亮或造成拖尾污染。可独立关闭“显示地理线索”，关闭分区环境也隐藏地形。精灵外观和光晕规则保留。截图desktop-stage/geography-v2.3.0.png及ui-v2.3.0.png，实际辨识度待

双亲繁殖默认开启，允许低概率出芽默认开启，出芽机会率默认0.003/活动秒（滑条0–0.05），仍需成熟、储能≥1.45与繁殖冷却，使用1-exp(-rate×dt)抽取。不是每帧0.3%，也不是0.3%的出生事件。没有配对时才尝试出芽。两种繁殖可独立关闭，双关不再出生，迁入救援由独立开关决定；仅低概率出芽未必维持种群。

配对双方能量≥1.05，成熟年龄仍为12+16×longevity，繁殖间隔仍为14+22×longevity；在26×世界尺度范围内找最近相容的成熟伙伴。八轴相似度阈值0.72-0.12×平均容忍度，不读祖系/类别标签，不指定性别。成熟且可繁殖者对相容伙伴有轻度靠近力，随social提高，独行者仍可偶遇配对。双方出生后都进入冷却，禁止同一步重复参与；幼体不能立即再配对，种群上限仍生效。

双方各投入45%现有储能，投入总量85%成为一个幼体、15%记入reproductionCost，双方各保留55%；无凭空奖励能量。幼体出生于两亲环绕距离的中点，速度由双方平均，复用既有跟随子代的出生提示。每个位点随机继承一亲，之后按原出生级概率/幅度突变，突变方向以重组后的基因为基础。无突变也可因重组改变组合，不计入“变异出生”。保持单胎和既有幼体成熟机制，暂不增加多胎与独立育幼状态。

记录parent和secondParent两个稳定ID，数组压缩时同步复制；generation取两亲较高者+1。旧lineage作为来源标签，从两亲择一继承，仅用于观察，不代表全部双亲祖先，更不决定相容性/类群。当前相似类群仍按活体基因估算。观察区累计出生拆分为配对/出芽，分区列表按实际区域数生成。参数预设保存新开关/机会率，旧参数预设使用新默认值，从种子重建；geneSchema仍为2，因为八轴未改变，不承诺旧版本轨迹重现。

验证：共享回归分批覆盖189项通过、1跳过。旧出芽测试原假定一步必出生，现适配为隔离单亲等待随机出生，避免等待期间其他个体死亡/捕食改变原固定索引；修正后进化与配对11项通过。覆盖双方扣能/能量守恒、逐位重组、双亲ID/冷却、禁用/未成熟/储能不足/不相容、屏幕环绕配对、地图可复现/多拓扑/连续性/中心逆变换/资源偏置、显示与缩放/预设状态。未改旧生态内核或原生功能，未重复其长测。
