# v0.8.0 桌面背景模式：实机验收

本版范围：真正的桌面宿主嵌入、预览/设置窗口、托盘与热键、性能信息显示开关。
后台节能和彩蛋留在后续阶段，尚未实现。

## 操作方式

- 手动启动：打开普通设置/预览窗口。
- “桌面壁纸”按钮：尝试将画面嵌入 Windows 桌面图标下方，隐藏控制台。
- 托盘“打开设置 / 预览”或 Ctrl+Alt+P：恢复可操作窗口。
- 托盘“进入桌面壁纸”：再次嵌入。
- 设置中“显示性能信息”：默认关闭，勾选后左上角显示性能统计，重启保留选择。
- 关闭设置窗口：尝试回到壁纸模式。彻底退出请用托盘“退出”。
- 开机自启：前端完成初始化后尝试进入壁纸模式。失败时保留设置窗口并显示错误。

## 需要在 Windows 实测

1. 壁纸模式下：桌面图标可见；双击图标、拖动图标、桌面空白处右键均正常。
2. 任务栏、开始菜单和 Win+D 不受干扰。
3. 托盘与快捷键都能回到设置，并且鼠标恢复交互；反复切换后画面仍正常。
4. 初次进入壁纸模式时不显示控制台、穿透提示或性能信息；主动打开性能信息后允许显示。
5. 嵌入不支持时能够看到错误，仍可操作设置窗口，不留下全屏穿透窗口。
6. 验证锁屏恢复、Explorer 重启、显示器拔插、不同 DPI 与虚拟桌面；这些尚不能仅凭编译结果判定通过。

## 当前限制

- 首版目标为 Windows x64 主屏，尚未承诺多屏。
- WorkerW 发现依赖 Windows Shell 非公开行为；不兼容时回退到设置，不能保证所有 Windows 版本均成功。
- 尚未自动重建 Explorer 重启后丢失的桌面宿主。
- 桌面模式转换使用同一个模拟与渲染实例；窗口尺寸变化沿用已有边界调整逻辑。
- 未加入后台节能或改动光效、动力学参数。
