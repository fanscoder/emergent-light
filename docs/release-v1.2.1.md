# v1.2.1 头领维护


## 2026-11-06：v1.2.1 头领维护（待视觉验收）

要求小环改芒星、头领更耐攻击，以及鱼群在头领身边更易繁殖成群。选择多次受击方案，不提前实现捍卫者/肉盾。

标记改为固定柔和四芒星，纵向半径4.2/横向3.4 CSS像素、内凹0.8像素；保留同色、4秒显现、生命/亮度衰减和独立透明覆盖层，不旋转/不闪烁/不写进拖尾。

两种生态模式的被捕食者头领需要三次有效接触攻击才被捕食，受击间隔至少1活动秒，避免每1/60秒连扣。仅最后一击计捕食、给能量和发死亡提示；普通个体仍一次捕食。伤势不回复，年龄/饥饿仍可死亡；受击计数与受击时间跟随索引压缩复制、出生/重开清零，不继承。无额外受击闪光。

仅生态鱼群的普通被捕食者向220×尺度内最近的同类头领跟随，目标位于头领运动方向后方约28×尺度，使用原个性大小因子提供松散侧向/纵向差异，有限吸引力加速度加速度匹配，不锁定队形或位置；保留觅食、逃生和局部分离。移除普通被捕食者旧的中心点短程吸引，围猎捕食者跟随不改。无额外全粒子邻居扫描：每步索引现有最多8个头领。

鱼群同种头领110×尺度附近（含头领自身）繁殖条件为能量1.5/成熟12秒/间隔8秒；其他被捕食者为1.65/18秒/24秒。初始成人没有本轮繁殖记录时可在成熟与能量满足后繁殖；新生幼体受年龄/冷却约束。出芽仍亲代55%/子代35%，消耗10%，不白送能量。捕食者30/75秒规则保留。粒子生命运动和繁殖门槛不改，头领耐受攻击会自然改变其种群轨迹，不能声称该模式完全未改。

验证：前端149通过、1跳过，原生6通过，TypeScript通过。新增测试覆盖三击/保护间隔/换位保伤/无提前能量与死亡提示、近头领出芽优势/同种限定/出芽能量预算与冷却、粒子生命原门槛和远程尾随。四组各5分钟救援关闭均保留两级种群；各15分钟默认长跑、头领限额及人口账目通过，均未迁入。单种子五个每分钟快照A/B对照，靠近头领的跟随者比例平均0.387→0.670，位于头领后方比例0.431→0.656，不代表所有种子和画面保证。数据文件见docs/ecology-validation-v1.2.1.json、ecology-soak-v1.2.1.json、school-cohesion-v1.2.1.json。
