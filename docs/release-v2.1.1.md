# v2.1.1 观察工具维护

## 2026-11-07：v2.1.1 观察工具维护（待实机验收）

观察工具使用补丁版本号。本轮不调整遗传、捕食、能量收益、繁殖和环境规则。下轮才做环境/取食闭环，最后两两繁殖。

近期统计采用最近120秒模拟时间的一秒累计检查点，边缘误差不足约1模拟秒，暂停不会老化；记录有界，不累积无限历史。平均死亡年龄只取近期死亡样本，显示样本数，无样本显示“暂无样本”。近期出生、交锋、战斗死亡与累计计数区分显示。存活属性均值仍取当前个体，另列非循环七轴10%–90%分位；色相循环，不用线性区间误导。

原“存续谱系”更名“存活祖系”，按最初祖先记录；新增“当前相似类群”近似估算，与祖先标签无关。每5秒观察八轴加权遗传距离，按稳定个体ID顺序分配到距离≤0.16的最近代表，不使用邻接链无限合并；至少3个体成组，1–2个体归零散。展示最近3次计数的中位数，零散数是最近样本；显示约等号，并在指南公开方法。初始独立随机八轴可能出现大量零散个体，阈值分组不是严格物种，也不是完整聚类谱系图。统计不参与行为，不消耗模拟随机序列。

进化模式滑条增加短提示：亲子更相似、更多子代发生变化、单次变化更大等，描述机制而不保证多样性。其他模式控件保持原样。实验范围开关默认关闭，仅进化模式开放初始个体与上限至1000；实际存储、空间索引、个体辅助数组与Canvas渲染缓存均支持1000，正常初始范围300、上限450。关闭开关不删除个体，也不强制改写已设置的高值；滑条恢复常规可选范围，下一次主动选择高值必须解锁。导入高数量预设须含experimentalRange:true；常规范围预设仍按常规限值校验。更高数量不自动增加食物。

验证：共享回归分批覆盖178项通过、1跳过；首轮1000个体测试超默认5秒限时，调整为30秒后通过；零界面依赖检查曾误匹配注释中的英文，改注释后通过。专项覆盖近期死亡退出、无样本、重置、色相环绕、同祖分化可分组、1000实际容量/预设、锁定不删除存活个体，以及读取观察不改变轨迹和能量结果。未修改旧生态内核，未重复其长测。1000个体、1920×1080、120个模拟步的本机测试首轮耗时约11秒，包含测试运行开销，不能推断安装版帧率；实验范围不承诺满帧。
