# v2.1.0 设计与实现：稳定谱系、相关变异与可辨识表型

2026-11-06。但观察到战斗死亡频繁、新类群难以延续，要求建立软性遗传关联，并加入寿命与速度遗传。设计已于2026-11-07实现并验证，最终规则与结果见release-v2.1.0.md，实机观感待验收。

## 已核实的原因

- 当前一次交锋必有死亡，战力相差不足约20%时双方死亡；相似的亲子/同群成员也可能互灭。样本42在300秒内出生565、战斗死亡547、老死64，最终134个体。人口存续不等于谱系稳定。
- 攻击概率每1/60秒接触时重复抽取，单次概率不高也可能迅速累计成高事件概率。新规则应使用每秒事件率p=1-exp(-rate*dt)，并区分接近/威吓/实际攻击。
- 变异率0.12按每个基因抽取，六轴至少一项变异概率约53.6%；增加两轴而不改变抽样方式会升到约64%。
- 初始六轴独立均匀，缺乏相关方向；寿命仍重新随机，速度仍全局加非遗传个性，谱系缺乏完整性。
- 小核心同时叠加多条视觉线索，并受即时能量缩放，导致成年个体的身份轮廓不够稳定。

## 下一版八轴

保留diet食性、aggression进攻意愿、strength攻击能力、social群体性、tolerance差异容忍度、hue色相，新增longevity寿命和pace速度。全部归一化，分别映射物理基准。各轴仍独立储存；关系只影响发生变异时的方向与机会，不把个体归入固定类别。

## 软性关联目标

| 条件 | 变异方向倾向 | 强度 |
|---|---|---|
| 偏营养颗粒利用 | 进攻意愿下降、群体性上升 | 强 |
| 中间食性 | 进攻意愿偏低、群体性偏中间 | 中/弱 |
| 偏其他个体能量利用 | 进攻意愿上升；群体性保留宽范围 | 强/无单向约束 |
| 进攻意愿高 | 攻击能力增加略易出现 | 弱 |
| 攻击能力高 | 进攻意愿增加略易出现 | 弱 |
| 偏肉食且低群体性 | 长寿、较高攻击能力略易出现 | 中 |
| 低差异容忍度 | 影响驱离，不直接增加进攻意愿 | 无直接关联 |
| 高速度 | 较高能耗，长寿同时出现须付出额外代价 | 生理成本为主 |
| 长寿 | 更慢成熟/更长繁殖间隔 | 由生命周期规则实现 |
| 色相 | 主要跟随亲代，突变较少 | 低变异权重 |

食性不直接决定攻击能力；捕食倾向与能力的联系可经进攻意愿和独行倾向间接产生。允许少见反例：强壮草食者、怯懦杂食者、独猎与群猎。这里是观赏生态的设计假设，不宣称普遍生物学定律。

## 变异与战斗建议

- 变异先按出生事件抽取，暂以约12%子代发生变异为起点；通常只修改一个位点，少量两个，其他位点精确继承。色相更慢变化，步幅较小；系数留待验证。
- 被选中位点的变化方向受上述关系网偏置，保留逆向概率，不每代把所有位点拉向固定模板。
- 大幅降低整体主动攻击事件率。排斥首先表现为驱离/绕开，不等同攻击。
- 普通冲突消耗既有能量、触发退让与恢复间隔；真正致死与互灭成为更少见结果，避免相近战力默认互灭。不同时引入复杂生命值系统。
- 高攻击能力/高速仍付出持续成本；长寿需要更长的成长和繁殖等待，避免全属性无成本增强。

## 视觉建议

于2026-11-06确定以下视觉映射，后续实现以此表为准：

| 外观 | 主要表达 |
|---|---|
| 核心半径 | 寿命倾向 |
| 芒尖锐利程度 | 进攻欲望 |
| 芒尖数量 | 攻击强度 |
| 核心延展程度 | 速度倾向 |
| 侧点、外弧 | 群体性、差异容忍度 |
| 慢变的色相 | 家族特征 |

成年核心轮廓以遗传基准稳定呈现，能量主要改变光晕与亮度，幼体再叠加成长比例。长寿倾向提高基准核心半径，不直接代表更强战力；攻击强度由芒尖数量表达，与进攻欲望的尖锐程度分开。核心延展表达速度倾向，不再沿用2.0.0的食性延展映射。本轮不另加未经确认的食性图纹；食性仍通过行为和观察信息表达。实际尺寸、芒尖档位、弧线强度须通过运动画面验收，避免线索叠成细碎噪点。运行代码已按此映射实现。

## 验证重点

比较同种子战斗死亡/出生比、实际存活时长、亲缘谱系延续、成年轮廓稳定性、稀有组合能否出现、长期属性是否全部趋近同一极值。保留能量/人口账目、边界和可复现性检查。先稳定战斗与继承，再加入八轴关联及表型；双亲繁殖继续后置。
