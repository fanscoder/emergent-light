# v2.2.0 环境差异与取食闭环

## 2026-11-07：v2.2.0 环境差异与取食闭环（待实机验收）

本轮仅更新独立进化模式：空间资源差异、可通行边界、有效猎食及相应观察。八轴继承/变异、外观、出芽和现有生理维持成本不改；旧四模式不改。双亲繁殖及其他新增点子继续后推。

环境为归一化三列两行、周期环绕的六区域；中心资源权重为0.3/0.45/0.8/1.25/1.5/1.7，按种子独立洗牌，均值1。资源用平滑插值过渡，默认差异0.85，实际中心权重0.405–1.595。以独立食物随机流做拒绝采样，只改变补给位置；初始500颗粒、总foodRate、1400颗粒容量及原洋流漂移保留，不人为增加总供能。分区观察显示中心权重而非全区实际补给率；区域内实际值连续变化。

区域边界为连续阻力带，交叉处仍能通过，沿线留有低阻通道；速度按exp(-阻力×隔离系数×5×dt)衰减，默认隔离0.7。零隔离自由穿越，最大隔离也不封死。没有穿墙弹回或个体归属锁定。食物仍按原洋流漂移，边界不是实体墙。不另画明亮网格或改变背景。跨区计数为个体单步区域编号变化的累计次数，可含来回穿越，不等于定居迁入次数。

猎食是个体当次行为，不赋予物种或角色。发生接触交锋后，猎食意图概率=diet²×clamp((1.45-energy)/0.9,0,1)；进攻欲望仍影响目标评分、追逐努力与接触机会。目标选择考虑对方储能，不只盯濒饿目标。主动猎食的接触事件率随饥饿食性提高，仍使用连续时间换算和6秒交锋间隔。未发生猎食时保留上一版普通冲突/退让规则。

相对能力不含食性或额外速度伤害；速度通过追上与逃脱发挥作用。猎食中战力比>1.15时捕获；<0.8时20%反杀，其余退让；中间范围1.5%同归于尽、随后约22%×战力比²概率捕获，剩余退让。强壮食草者仍可反抗；不按食性限制其战力。成功转移最多猎物当前储能×0.85×胜者diet，并受胜者1.8储能上限限制；未转移部分记为战斗损耗。未另造肉食能量或身体储备。普通冲突转移仍为原0.65效率。猎食失败耗能并退让，不能免费无限试探。

首轮长测显示增加收益后捕获仍很少，核查到通用14像素避碰与小评分追逐相抵消。最终版本把目标评分用于选择，另以饥饿食性×进攻欲望形成追逐努力，接近选中目标时部分克服避碰；没有降低全体个体避碰。新增实际运动追猎测试，确认更快、饥饿且有战力的追猎者能追上移动目标；速度不直接叠加伤害。

面板新增“分区环境”“资源差异”“区间阻力”“有效猎食”，默认开启环境与猎食；可分别关闭做对照，关闭环境不清除或重新撒已有食物，新补给逐步转为均匀。默认恢复与旧schema参数预设使用新版本默认环境；不保证旧种子逐帧复现旧版本。统计增加累计猎食尝试/捕获/遭反杀/转移能量、六区域人口与平均肉食倾向。猎食双方互灭计入战斗死亡但不计单方捕获或反杀；统计不参与行为。
