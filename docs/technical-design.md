# 架构与生态规则概览

基线：v2.3.0。本文件描述当前结构与主要取舍；历史公式、数值和验证细节见各版本记录，不能把不同时期的规则同时视为现行设计。

## 架构

TypeScript模拟核心使用TypedArray存储个体状态，以固定步长推进；渲染读取只读状态并按最短环绕路径插值。空间哈希负责邻域查询，不截断密集格邻居。力曲线、积分、随机数、互动和事件线索分别封装。

Canvas 2D使用缓存光晕精灵、低分辨率离屏光晕层与独立核心/事件绘制，避免逐个体shadowBlur。性能基准曾显示主要瓶颈位于模拟侧，因此维持Canvas后端；是否改用其他后端应以新基准决定。

界面为原生DOM与CSS，包含浮动面板、参数规格、预设及状态持久化。Tauri承担Windows桌面嵌入、托盘、自启和节能。核心逻辑不依赖这些平台接口。

## 模式边界

粒子生命与鱼群保留原规则。两种旧生态模式加入营养颗粒、能量、寿命、出芽及有限头领/护卫行为。独立进化模式取消固定物种与职位，采用个体属性、遗传相似性及局部行为；不同模式不共享后续规则改动。

## 遗传与相容性

八轴归一化属性为食性、进攻欲望、攻击强度、群体性、差异容忍度、循环色相、寿命与速度。各轴独立存储，软性关联仅影响发生突变时的变化方向，保留逆向变化，不把个体强制拉向模板。

出生级突变默认约12%，通常改变一个位点，少量两个；色相的突变机会与步幅更小。双亲逐位重组后再突变。相容性使用加权遗传距离，色相按环绕距离计算；临时能量、年龄和装饰染色不参与遗传距离。

偏颗粒利用倾向更易产生低进攻与高群体性；中间食性群体性偏均衡；低群体性肉食倾向与较高战力/寿命存在软关联。攻击能力不由食性身份决定，强壮食草者与怯懦杂食者仍可能存在。

## 能量与生命周期

营养收益随食性变化，猎食只转移目标已有储能，吸收效率及容量上限之外的部分计为损耗。高速与高战力维持成本更高；长寿同时带来更晚成熟与更长繁殖等待。普通冲突主要耗能并退让，猎食按相对能力结算，允许失败、反杀与少量互灭。

配对需双方成熟、储能足够、相容且在接触范围内。双方各投入45%储能，投入的85%形成一个幼体，其余计入繁殖损耗；双方同时进入冷却。子代记录两个亲本ID，来源标签择一继承，不能视为完整家谱。出芽保留为可关闭的低概率补充，默认机会率0.003/模拟秒。两种繁殖与低种群迁入救援分别控制。

## 种子地理

种子决定2–4列、2–3行的区域结构、资源权重、曲线变形与通道。周期双剪切保持归一化地理连续且可逆；资源权重均值归一化，平滑插值与拒绝采样改变补给位置，不增加总补给率。边界为有通道的阻力带，不是封闭墙体。

地理背景直接读取同一环境对象，缓存成低分辨率暗色底图，并作为普通渐隐目标，不进入加色光晕累积。世界缩放保持归一化地形。

## 观察与验证

约120秒模拟时间窗口用于近期事件与死亡年龄，显示样本数，无样本时明确说明。当前相似类群按活体基因近似聚合并短时平滑，祖系标签仅用于来源观察。均值和分位区间描述当前个体，累计计数明确标注。

验证分为单元/回归、人口与能量账目、多种子模拟、模式开关对照、生产资源界面检查与平台验收。种子测试只是有限证据，不证明无限自维持或固定食性长期共存。完整历史结果见docs内验证报告及release记录。

## 关键取舍

- 规则变化优先通过能量、时间与空间机会体现，不采用隐藏奖励或类别保底。
- 环境差异本身不能替代有效取食；取食规则与地理因素需要分项对照。
- 属性、能量与表型复用已有机制，控制新增状态和计算量。
- 统计标签不反向定义物种；视觉相似不等于固定生物分类。
- 实验数量上限表示容量支持，实际帧率仍需按设备测量。
