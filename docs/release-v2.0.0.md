# v2.0.0 Mutant and Evolution


## 2026-11-06：v2.0.0 Mutant and Evolution · 第一阶段（待视觉验收）

新增独立进化模式，强调取消人为物种/觅食者/捕食者/头领/护卫身份，并将能量获取、进攻倾向和攻击能力拆开。首轮范围为个体遗传属性、出芽继承/变异、外观映射与相容性及基本交锋；双亲繁殖、持久族群关系和谱系展示另轮实现。

新增EvolutionSimulation，不改旧EcologySimulation的规则。共享createStore/空间哈希/运动积分/寿命/能量表现/营养颗粒/出芽提示/互动与彩蛋。旧四个模式保留，新模式入口“变异与进化”；不强制改变现有默认模式。旧模式种群配置在此隐藏，新增演化观察和变异概率/幅度滑条。恢复默认、预设导入导出、模式切换和悬浮面板均接入。

遗传六轴全部归一化0..1：diet能量获取倾向、aggression进攻倾向、strength攻击能力、social社交倾向、tolerance差异容忍度、hue循环色相。初始个体各轴独立采样，不预先分组；交通字段type固定0仅兼容共享存储，不参与新模式行为。新状态无leader/guard字段，无族群ID或职位选举。当前存活个体记录独立id、单亲parent id和generation，死亡移除后不保留无限家谱。

schema版本1的GENE_DEFS集中定义属性、循环性和相似度权重。出芽逐项继承，默认每项0.12概率变异，幅度基准0.055；通常小幅正态偏移，发生变异时2.5%机会使用3倍幅度；边界钳制，色相环绕。无额外遗传属性随机漂移。纯inheritGenome预留可选第二亲本的逐位重组，已有单测，但运行模式尚不配对、不双亲繁殖。预设按种子重建，不是完整生态快照；含geneSchema，未知版本导入显示错误且保留原模拟，启动恢复失败则使用默认规则并提示。

每个个体均能利用营养颗粒并有交锋机会。营养收益0.16×(1-0.75×diet)；获胜转移对方能量最多0.65×diet，且不超过自身1.8储能上限。偏营养且好斗者可以击杀但获取很少肉食能量。进攻/逃离由aggression、饥饿、邻居相似性和预估风险共同驱动，未把食性当作战斗身份。

相对战力由strength、当前能量和成长程度计算；相差超过约20%时强者存活，否则双方死亡。任何个体两次有效交锋至少间隔2活动秒，避免每帧重复结算。高strength增加平方维持消耗并略降速度上限，避免所有属性都是无代价增强。出芽需能量1.45、年龄16秒、约18秒间隔（原个体差异修正），亲代保留55%/子代35%，损耗10%；子代年龄0，成熟前战力较弱，3秒内不被作为主动攻击目标。自然死亡不闪烁，战斗和出生复用有限、平滑局部提示；出生提示继续跟随子代。

空间哈希范围内比较六轴加权距离，色相使用环绕距离；能量、年龄、临时彩蛋染色不参与遗传相似度。tolerance确定接近/排斥阈值，social调聚集，允许差异个体和相似个体因资源与风险形成不同结果。第一阶段未建立长期接纳记忆/族群分裂制度；当前是局部相容性和行为基础，不宣称已完成完整群体竞争。

外观直接使用同组基因：24档缓存色相（临时绿色彩蛋仍平滑覆盖且不改基因）；核心横向伸展表达diet，尖锐程度表达aggression，3–6芒尖表达strength，侧点展开表达social，细弧表达tolerance；是遗传表型，不再是职位标记。亮度/光晕/成长继续表达即时能量和寿命。形态/颜色有绘制离散化，小基因差异不保证肉眼可分；相似度比较底层表型属性，不读取像素。精灵按需缓存，最多24×16档，不为每个体分配光晕位图；运动预估战力每步缓存，避免每邻居反复计算。

验证：168项前端回归通过、1跳过，覆盖新遗传/战斗/能量账目与共享旧功能；未重复未修改旧生态内核的长测文件。新增3种子各300模拟秒、救援关闭长跑，人口账目/能量账目（含热损耗与自然死亡丢失）及基因/状态边界通过。每30秒采样；minimumPopulation/peakPopulation为采样统计，不是逐步极值。三个样本最终134/138/151个体，最高8/10/7代，发生变异出生300/285/308次，迁入均0。有限样本存在偏营养颗粒利用型占优，不保证各食性长期共存，也不保证无限自维持。当前允许选择和谱系消亡，不设类别保底。

生产浏览器9组验收通过：五种模式入口、新观察区、旧物种面板隐藏、变异滑条、默认恢复、未知遗传版本错误提示、有效遗传预设导入、切回旧生态控制台及无运行异常。截图desktop-stage/ui-v2.0.0.png；数据docs/evolution-validation-v2.0.0.json与ui-validation-v2.0.0.json。原生6项、TypeScript/Vite、Windows release及NSIS安装包通过。实际桌面观感与设备帧率待
